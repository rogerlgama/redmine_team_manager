# Changelog

All notable changes to this project are documented here.

## 0.3.38

- Prepare the first public release documentation.
- Adopt the `GPL-2.0-or-later` license.
- Remove the placeholder project URL from plugin metadata.

## 0.3.37

- Ensure the legacy **Status** column is absent from the generated wiki report.

## 0.3.36

- Remove the **Status** column from the wiki report summary.

## 0.3.35

- Remove lock/unlock actions and the active-state controls from team administration.
- Add migration 006 to reactivate legacy teams.

## 0.3.34

- Load searchable selector assets on the report screen.
- Improve Textile report layout and MySQL three-byte `utf8` compatibility.

## 0.3.27–0.3.30

- Add administrator-only JSON API endpoints for teams, members, and projects.
- Add wiki report creation and updates.
- Improve report layout and Unicode handling.

## 0.3.13–0.3.26

- Display teams in project overview.
- Restrict team management to administrators.
- Hide technical groups from native member selectors.
- Add collective issue assignment and searchable user/project selectors.

## 0.3.0–0.3.12

- Remove the team base role while retaining individual member roles.
- Improve synchronization, unlink safety, and member management.

## 0.1.0–0.2.0

- Initial team, member, role, and project synchronization implementation.
